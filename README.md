# Hola! Soy Josefina 👋

Soy Analista de Datos y actualmente estoy finalizando mi Doctorado en Ingeniería, donde durante los últimos años trabajé desarrollando pipelines de datos, modelos predictivos y análisis espacio-temporales aplicados a problemas reales.

Este GitHub es el lugar donde voy documentando mi aprendizaje, compartiendo proyectos y probando distintas herramientas de análisis de datos, Machine Learning y visualización. Encontrarás desde proyectos completos hasta prácticas, experimentos y notebooks donde exploro nuevas técnicas y herramientas.

Siempre estoy buscando aprender algo nuevo y mejorar la forma en la que analizo, interpreto y comunico datos.

---

## 💻 Sobre mí

Me gusta trabajar con datos desde el proceso completo: obtenerlos, limpiarlos, explorarlos, analizarlos, construir modelos y finalmente transformarlos en información útil para responder preguntas o facilitar la toma de decisiones.

Mi experiencia viene principalmente del análisis ambiental y geoespacial, aunque actualmente estoy ampliando mi portfolio hacia proyectos de Data Analytics y Machine Learning aplicados a distintos tipos de datasets.

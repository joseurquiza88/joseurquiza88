# 👋 Hola, soy Josefina 

### 📊 Data Analyst | Business Intelligence | Python · SQL · Power BI

Soy **Analista de Datos**, con formación en ingeniería y experiencia en investigación científica y operaciones de negocio. A lo largo de mi trayectoria trabajé con datos de múltiples fuentes, desarrollando procesos de integración, limpieza y transformación, análisis estadístico, modelos predictivos y visualizaciones.

Mi experiencia combina el análisis de datos ambientales y geoespaciales con el trabajo sobre información financiera, administrativa y operativa en una empresa. Esto me permite abordar problemas desde distintas perspectivas, desde la preparación de los datos hasta la generación de indicadores e información útil para la toma de decisiones.

Actualmente estoy enfocada en **Data Analytics y Business Intelligence**, profundizando en SQL, Power BI, Python y modelado de datos, mientras desarrollo proyectos prácticos aplicados a problemas de negocio.

## 🚀 Proyectos destacados

### 📊 Data Analytics & Business Intelligence

**Financial Analytics Dashboard | Power BI · DAX · PostgreSQL · Python**

Proyecto de análisis financiero orientado al seguimiento de indicadores, la evolución de resultados y el análisis de la estructura financiera, liquidez y endeudamiento. Incluye integración y transformación de datos, modelado y desarrollo de medidas DAX para generar información útil para la toma de decisiones.

### 🐍 Data Engineering & ETL

**Automated Financial Data Pipeline | Python · Pandas · PostgreSQL · Databricks**

Proyecto de automatización del procesamiento de información financiera a partir de extractos bancarios en PDF. Incluye extracción y normalización de datos, transformación con Python y Pandas, almacenamiento en PostgreSQL y trabajo con tablas Delta en Databricks.

### 🗄️ SQL & Data Analysis

**SQL Projects & Queries | PostgreSQL · MySQL · SQL Server**

Repositorio de prácticas y proyectos de SQL, con más de 100 consultas desarrolladas sobre el dataset de comercio electrónico de Olist. Incluye consultas básicas, intermedias y avanzadas, joins, subconsultas, CTE, funciones de ventana y ranking, además de ejercicios de limpieza de datos, análisis de ventas y diseño de bases de datos relacionales.

🔗 [Ver repositorio de SQL](https://github.com/joseurquiza88/Proyectos-SQL)

### 🤖 Predictive Modeling & Environmental Data

**PM2.5 Prediction | Python · R · Machine Learning · Satellite Data**

Investigación doctoral centrada en la estimación de concentraciones de PM2.5 en centros urbanos de América Latina mediante datos satelitales, meteorológicos y geoespaciales. Incluyó integración de múltiples fuentes, análisis estadístico, desarrollo y evaluación de modelos predictivos y generación de mapas de distribución espacial.

### 🌎 Spatial & Spatio-temporal Data Analysis

**Spatio-temporal Data Analysis | Python · R · QGIS · GIS**

Procesamiento, integración y análisis de datos espaciales y temporales procedentes de múltiples fuentes, trabajando con distintas escalas geográficas y períodos de estudio. Experiencia aplicada al análisis de patrones, la modelización y la visualización de información geoespacial.

### 📦 R Package Development

**AirExposure | R · Spatial Data · Shiny**

Desarrollo de un paquete de R para estimar la exposición a contaminantes atmosféricos considerando patrones de movilidad y actividades diarias. Incluye herramientas para el procesamiento de datos espaciales y la visualización interactiva de resultados.

### 📈 Data Visualization & Interactive Applications

**Interactive Dashboards & Data Visualization | Power BI · Plotly · Shiny · Streamlit**

Desarrollo de visualizaciones, dashboards y aplicaciones interactivas para explorar datos, comunicar resultados e identificar patrones. Incluye proyectos de visualización empresarial y aplicaciones vinculadas al análisis de datos científicos y geoespaciales.

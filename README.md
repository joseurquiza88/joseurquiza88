## 🚀 Proyectos mas destacados

### 📊 Data Analytics & Business Intelligence

**Financial Analytics Dashboard: Power BI · DAX · PostgreSQL · Python**

Dashboard financiero desarrollado para analizar la evolución de indicadores,
estructura financiera, liquidez y endeudamiento. Incluye integración de datos,
transformaciones con Power Query, modelado y medidas DAX.

---

### 🐍 Data Engineering & ETL

**Automated Financial Data Pipeline: Python · Pandas · PostgreSQL · Databricks**

Pipeline desarrollado para automatizar la extracción y transformación de
información desde extractos bancarios en PDF. Incluye procesamiento de texto,
normalización de datos, transformación con Pandas/Spark y almacenamiento en
Delta Lake.

---

### 🤖 Machine Learning & Environmental Data

**PM2.5 Prediction: Python · R · Machine Learning · GIS · Satellite Data**

Desarrollo de modelos predictivos para estimar concentraciones de PM2.5
integrando información satelital, meteorológica y geoespacial. Se evaluaron
modelos como Random Forest, XGBoost, Extra Trees y Support Vector Regression.

---

### 🌎 Spatial Data & GIS

**Spatio-temporal Data Analysis: Python · R · QGIS · GIS**

Procesamiento, integración y análisis de datos espaciales y temporales,
trabajando con múltiples fuentes y diferentes escalas geográficas.

---

### 📦 R Package Development

**AirExposure: R · Spatial Data · Shiny**

Desarrollo de un paquete de R para estimar exposición a contaminantes
atmosféricos considerando patrones de movilidad y actividades diarias,
incluyendo herramientas de análisis y visualización interactiva.

---

### 📈 Data Visualization & Interactive Applications

Desarrollo de dashboards, reportes y aplicaciones interactivas utilizando
**Power BI, Plotly, ggplot2, Matplotlib, Shiny y Streamlit**.

---

### 🗄️ SQL & Data Analysis

Prácticas y proyectos de análisis utilizando **PostgreSQL, MySQL y SQLite**,
incluyendo consultas complejas, CTEs, subqueries, agregaciones, JOINs y
funciones de ventana.

Este repositorio seguirá creciendo con nuevos proyectos a medida que continúe aprendiendo y explorando nuevas herramientas.
